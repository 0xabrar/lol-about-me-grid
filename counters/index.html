    Methodology

    How the counter score is built

    01

    Same lane only

    `matchId` + opposite team + same `teamPosition`.

    02

    15-minute lane state

    Nearest 15:00 frame for gold, XP, and CS deltas.

    03

    Baseline adjusted

    Matchup performance minus that champion's lane average.

    04

    Lane first

    Counter score weights lane score more than game result.

    Lane score gold15 + xp15 + cs15 + K/D
    Game score win-rate delta + damage delta
    Counter score 62% lane score + 38% game score
